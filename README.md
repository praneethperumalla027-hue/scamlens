# 🔍 ScamLens

> An AI-assisted message verification tool to help people detect suspicious offers, scholarships, job postings, and payment requests.

---

## 💡 About ScamLens

ScamLens helps everyday users analyze suspicious messages (such as unsolicited internship offers, fake scholarship alerts, lottery winnings, or urgent payment requests) to identify potential scam indicators before they fall victim to fraud.

> **Disclaimer:** ScamLens provides risk assessments and educational guidance based on detected patterns. It is an advisory tool and does not guarantee that a message is completely safe or fraudulent. Always exercise caution and verify directly with official organizations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla, no framework bloat)
- **Backend:** Java (REST API server)
- **AI Integration:** Google Gemma API (integrated via secure backend proxy)
- **Version Control:** Git & GitHub
